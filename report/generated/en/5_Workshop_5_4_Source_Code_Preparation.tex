\vspace{0.5em}\noindent\textbf{Source Code Preparation}\par

\vspace{0.5em}\noindent\textbf{Objective}\par

Prepare the application repository for repeatable validation and
deployment without exposing secrets or modifying production resources
accidentally.

\vspace{0.5em}\noindent\textbf{Architecture context}\par

The repository is a multi-service application. CI/CD builds separate
backend, chat, and optional AI images, deploys Kubernetes manifests, and
builds the frontend separately for S3 and CloudFront.

\vspace{0.5em}\noindent\textbf{Deployment preparation}\par

Before running production workflows:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Confirm GitHub production variables and secrets are configured.
\item
  Confirm OIDC role \texttt{internship-\allowbreak{}github-\allowbreak{}deploy} can assume the
  intended AWS account.
\item
  Confirm ECR repositories exist for backend, chat, and AI if AI
  deployment is enabled.
\item
  Confirm RDS, Redis, DynamoDB, SQS, S3, CloudFront, ALB, Lambda, SES,
  and SageMaker readiness.
\item
  Confirm \texttt{PROCESSING\_\allowbreak{}WORKER\_\allowbreak{}ENABLED} is false unless AI
  dependencies are ready.
\item
  Use \texttt{deploy-\allowbreak{}app} for EKS application deployment and
  \texttt{deploy-\allowbreak{}frontend} for frontend deployment.
\end{enumerate}
