## Checklist

- [ ] Delete application deployment.
- [ ] Delete API resources.
- [ ] Delete compute resources.
- [ ] Delete database resources.
- [ ] Delete database snapshots if not required.
- [ ] Empty and delete storage buckets.
- [ ] Delete log groups and alarms.
- [ ] Release public IP addresses.
- [ ] Delete unused Security Groups.
- [ ] Delete unused IAM policies and roles.
- [ ] Review AWS Billing.
- [ ] Confirm no billable resources remain.

Do not delete shared team resources without authorization.
