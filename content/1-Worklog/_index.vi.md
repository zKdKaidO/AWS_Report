# Nhật ký thực tập

Nhật ký thực tập ghi lại quá trình phát triển project AI-Powered Internship Application Tracker trong 8 tuần, từ 08/06/2026 đến 30/07/2026. Lịch báo cáo được chia theo từng tuần bắt đầu vào thứ hai; riêng tuần cuối được rút ngắn theo ngày kết thúc kỳ thực tập.

| Tuần | Thời gian | Nội dung chính |
|---|---|---|
| 1 | 08/06/2026 - 14/06/2026 | Định hướng chương trình, phân tích bài toán, nền tảng backend, database và authentication |
| 2 | 15/06/2026 - 21/06/2026 | Nền tảng Candidate-HR, applications, documents và Amazon S3 |
| 3 | 22/06/2026 - 28/06/2026 | React frontend, tích hợp REST API và protected user flows |
| 4 | 29/06/2026 - 05/07/2026 | Realtime chat với Socket.IO, Redis và DynamoDB |
| 5 | 06/07/2026 - 12/07/2026 | Tích hợp AI, asynchronous processing, idempotency và concurrency |
| 6 | 13/07/2026 - 19/07/2026 | Container hóa bằng Docker, tích hợp Docker Compose và local smoke testing |
| 7 | 20/07/2026 - 26/07/2026 | Kubernetes local bằng kind, scaling controls và observability |
| 8 | 27/07/2026 - 30/07/2026 | CI/CD, chuẩn bị triển khai AWS, end-to-end testing và hoàn thiện báo cáo |

Trang tổng quan này giúp theo dõi tiến độ chính của project theo từng tuần và liên hệ các đầu việc triển khai với kiến trúc hệ thống cũng như nội dung báo cáo cuối kỳ.
