# Events Participated

During the internship, I participated in four events and knowledge-sharing sessions related to AWS Cloud, enterprise architecture, Agentic AI, application security, and system operations. These activities helped me connect the knowledge gained during the project with practical examples of how Cloud and AI systems are designed, deployed, monitored, and protected in enterprise environments.

## Event Overview

### [Event 1 - FCAJ Community Day: Data Driven, AI Risen](4.1-Event1/)

This event focused on the role of data and artificial intelligence in digital-product development. The sessions helped me understand how data can be collected, processed, and applied to create AI solutions that provide practical value.

### [Event 2 - AWS Study Tour: Enterprise Cloud Architectures and Industry Applications](4.2-Event2/)

This event introduced how enterprises design and operate Cloud architectures on AWS. It provided a broader view of scalability, availability, security, cost management, and the selection of appropriate AWS services for different business requirements.

### [Event 3 - FCAJ x Agentic AI Build Week 2026](4.3-Event3/)

This event focused on Agentic AI and the development of AI systems capable of planning, using tools, and completing multi-step tasks. It helped me better understand how to identify user pain points, limit feature scope, and design AI Agents around practical needs rather than focusing only on model capability.

### [Event 4 - AWS Cloud Practitioner, Web Security and Monitoring](4.4-Event4/)

The event included three main topics: preparing for the AWS Certified Cloud Practitioner examination, securing web applications with AWS Security Agent, and building monitoring systems around indicators that reflect the actual user experience.

The sessions helped me understand the structure of the AWS Cloud Practitioner certification, how AI-supported tools can assist security reviews during development, and the difference between healthy infrastructure and a truly usable application. The SLA and monitoring session also demonstrated that technical health checks are insufficient when important business flows, such as login and core application functions, are not being monitored.

### [Event 5 - FCAJ x Agentic AI Build Week 2026](4.5-Event5/)

This event shared the journey of building Agentic AI products in a hackathon environment, from identifying real-world problems and designing AWS architectures to developing MVPs and presenting working demonstrations. The featured projects included the S.H.E.P.H.E.R.D. crowd-monitoring system, the multi-channel KFC Bot Agent, an AI-native application for Solution Architects, and the SignalScout corporate-strategy analysis platform.

The event helped me understand that an effective AI Agent requires more than a language model. It also depends on trusted data, actionable tools, business rules, cost awareness, and human supervision. The presentations also provided practical lessons about limiting MVP scope, defining team responsibilities, and completing a functional product under time pressure.

## Knowledge and Experience Gained

The four events provided a broader understanding of the lifecycle of Cloud and AI products, including:

- Identifying user pain points and selecting suitable solutions.
- Designing scalable AWS architectures with cost-control considerations.
- Building AI Agents and integrating AI into practical workflows.
- Applying security throughout application design and development.
- Monitoring logs, metrics, SLAs, and actual system behavior.
- Distinguishing infrastructure availability from a reliable user experience.
- Building foundational knowledge for future AWS certification study.

Through these events, I learned that technical knowledge represents only one part of product development. An effective solution must also address actual user needs, remain reliable, control operating costs, protect data, and provide meaningful value.

The knowledge gained from these four events will support the continued development of the internship project, particularly in AWS architecture, AI Agents, monitoring, data management, application security, and system operations.
